PROMPT — Integrazione USDA nativa in AlphaChat

Voglio trasformare USDA in una funzione nativa di AlphaChat.

L’utente NON deve percepire USDA come un’app esterna, un sito web o un servizio separato.

L’esperienza deve essere identica all’invio di una foto, un documento o una posizione.

L’integrazione deve riutilizzare integralmente il backend USDA già esistente, senza duplicare logica o compromettere la sicurezza.

⸻

Obiettivo

Quando un utente apre una chat privata o di gruppo deve poter:

* inviare USDA
* richiedere USDA
* vedere pagamenti ricevuti
* vedere pagamenti inviati
* vedere stato blockchain
* vedere ricevute
* vedere claim
* vedere refund

tutto come normali messaggi della conversazione.

Il destinatario non deve uscire dalla chat.

⸻

Filosofia

USDA NON deve sembrare un token esterno.

Deve sembrare una funzione nativa di AlphaChat.

Esattamente come:

* foto
* video
* posizione

anche USDA deve essere un “tipo messaggio”.

Sicurezza

Riutilizzare integralmente il backend USDA.

NON duplicare:

* wallet custodiali
* claim
* refund
* verify
* idempotenza
* RPC
* blockchain
* retry
* fee

Usare esclusivamente le API USDA esistenti quando possibile.

⸻

UX

L’utente deve percepire USDA come una funzione costruita dentro AlphaChat.

Mai dare la sensazione di aprire un servizio esterno.

Le animazioni devono essere fluide.

Le bubble devono avere un design dedicato.

Gli stati devono aggiornarsi in tempo reale tramite WebSocket.

Utilizzare optimistic update.

Mai bloccare la UI durante la firma.

⸻

Architettura

Prima di scrivere codice:

1. analizzare tutte le API USDA disponibili;
2. indicare quali endpoint vengono riutilizzati;
3. indicare quali endpoint nuovi sono realmente necessari;
4. produrre un diagramma completo del flusso;
5. individuare eventuali problemi di sicurezza o UX;
6. proporre eventuali miglioramenti mantenendo la piena compatibilità con il backend USDA esistente.

Obiettivo finale: realizzare un’integrazione che faccia percepire USDA come una capacità nativa di AlphaChat, con un’esperienza utente continua, elegante e sicura, senza uscire mai dall’app e sfruttando l’infrastruttura USDA già esistente.
