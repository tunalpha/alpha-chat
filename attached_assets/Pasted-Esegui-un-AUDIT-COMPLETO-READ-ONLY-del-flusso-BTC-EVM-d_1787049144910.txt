4. CRITERIO DI COMPLETAMENTO

Il nuovo comportamento corretto deve essere:

BTC payment confirmed
≠
swap completed

Lo swap può diventare completed SOLO quando esiste una prova reale del payout EVM.

Idealmente:

provider status DONE
+
correct receiving chain
+
destination transaction hash
+
destination transaction verificabile on-chain

Se il codice considera sufficiente un semplice DONE, segnalalo come rischio.

5. DESTINATION TX

BTC input TX ≠ EVM destination TX.

Se non esiste una destination TX EVM:
