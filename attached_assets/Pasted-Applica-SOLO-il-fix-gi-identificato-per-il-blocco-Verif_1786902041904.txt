Modifica richiesta

Nel useEffect di recovery di useSwapState, separa il controllo attuale:

if (cancelled || !active) return;

in:

if (cancelled) return;
if (!active) {
  _set({ recovering: false });
  return;
}

Il motivo è che:

GET /api/v1/swap/active → HTTP 204 → swapFetch() restituisce null → !active → il codice usciva senza mai impostare recovering: false.
