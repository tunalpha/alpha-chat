OBIETTIVO PRODOTTO:

Alpha Swap deve funzionare come:

TOKEN A → TOKEN B

L’utente sceglie:

1. rete;
2. token A da inviare;
3. token B da ricevere;
4. importo.

Il sistema deve automaticamente:

* leggere il saldo reale del token A dal wallet Alpha;
* impedire importi superiori al saldo spendibile;
* mostrare MAX corretto;
* ottenere la quote usando esattamente Token A → Token B sulla rete selezionata;
* mostrare il risultato reale;
* eseguire la transazione con Alpha Wallet.

4. IMPORTO E MAX

Questa è una regola ASSOLUTA:

amount <= spendableBalance

Mai il contrario.

MAX deve essere calcolato dal saldo reale.

Per token nativo:

MAX = balance - gasReserve

Per ERC-20:

MAX = tokenBalance

tenendo conto delle fee/gas quando necessario.

Non usare mai:

* valori minimi come fallback che superano il saldo;
* importi hardcoded;
* valori della quote come saldo;
* conversioni implicite sbagliate tra wei/token decimals.

Tutti gli importi interni devono essere gestiti in unità precise:

* bigint/raw units on-chain;
* decimals del token;
* conversione UI solo all’ingresso/uscita.

Aggiungi validazione finale immediatamente prima dell’execute:
amountRaw <= spendableBalanceRaw

Se non è vero:
BLOCCA la transazione.
