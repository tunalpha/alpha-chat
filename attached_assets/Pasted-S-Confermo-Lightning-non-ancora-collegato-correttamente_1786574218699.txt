Quindi il problema non è più il feature flag.

Devi tracciare il percorso reale:

spark_lightning_enabled=true
→ SparkWalletProvider
→ connect()
→ getMnemonic()
→ loadKeystore/decryptSeed
→ createBreezAdapter
→ Breez SDK connect
→ syncWallet
→ state=connected
→ sparkSat
→ AlphaWalletPage
→ riga Bitcoin Lightning.

1. Aggiungi temporaneamente diagnostica non sensibile, senza mai loggare mnemonic, PIN, private key o API key.

Devi sapere esattamente quale di questi passaggi fallisce.

2. Verifica soprattutto getMnemonic():

* sessionStorage["aw_bio_pin"] esiste davvero in produzione?
* loadKeystore() trova il wallet corretto?
* decryptSeed() riesce?
* il mnemonic viene passato correttamente al LiveSparkAdapter?

3. Verifica connect():

* viene effettivamente chiamato?
* quale stato assume il provider?
* quale errore restituisce, se fallisce?
* Breez SDK viene caricato?
* IndexedDB breez-poc-live-v1 viene aperta?

4. Verifica iOS Safari:

* crossOriginIsolated === true
* WASM caricato
* nessun errore CORS/COOP/COEP
* nessun errore IndexedDB
* nessun errore WalletConnect/Spark.

5. Verifica il rendering:
se connect() termina correttamente con saldo 0 sat, la riga Lightning DEVE comunque apparire.

6. NON usare il saldo per decidere se mostrare la riga.
0 sat è un saldo valido.

7. NON modificare:
BTC, EVM, USDA, MultiChain, WalletContext, Payment Engine, ChatPage o fee BTC.

8. NON disabilitare spark_lightning_enabled.
