FINAL SECRET CONFIGURATION — MULTI-CHAIN

Configura in modo sicuro tutti i Secrets necessari al Multi-Chain Payment Engine.

REGOLA ASSOLUTA:
NON chiedermi mai di incollare private key, seed phrase o secret nella chat.
NON stampare MAI il valore dei secret nei log, nei report, nei test o nel terminale.
NON salvare private key nel codice, .env committato, repository o file di configurazione versionati.

I secret devono essere inseriti esclusivamente tramite Replit Secrets / Environment Variables.

==================================================
5. SEPARAZIONE WALLET
==================================================

OBBLIGATORIO:

Gas Station Wallet ≠ Fee Wallet

Per ogni EVM:

GAS STATION
→ paga esclusivamente il gas blockchain.

FEE WALLET
→ riceve projectFee 0,10% + networkFeeCharged.

Non utilizzare la stessa address per entrambi.

==================================================
6. SECURITY CHECK
==================================================

Dopo la configurazione:

NON mostrare i valori.

Verificare solamente:

✓ secret presente
✓ secret non vuoto
✓ formato valido
✓ wallet address valida
✓ RPC raggiungibile
✓ chain ID corretto
✓ contratto token configurato
✓ fee wallet configurato
✓ gas station configurata

Nel report utilizzare esclusivamente:

PRESENT / MISSING / INVALID

mai il valore del secret.
